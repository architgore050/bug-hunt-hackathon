# be-ambitious

Status: installed for OpenCode on 2026-11-27.

`SKILL.md` is the unmodified upstream skill from [robonuggets/be-ambitious](https://github.com/robonuggets/be-ambitious), commit `dc116a3ebd8cf772e4d0930626f67369bd60399d`. The upstream MIT license is included in `LICENSE`.

The skill turns Felix Rieseberg's Altitude, Depth, and Range framework into a planning and execution workflow. It raises the outcome, standard, or range of perspectives without adding unnecessary scope, and requires an outside check rather than self-grading.

## Use in OpenCode

Mention `@be-ambitious` with a task, or use a natural-language trigger such as "be more ambitious with this" or "what would a top expert do here?"

The upstream skill text uses `/be-ambitious` for clients that support skill slash commands. In OpenCode, explicit `@be-ambitious` invocation and the description's natural-language triggers are the portable entry points.

Examples:

- `@be-ambitious improve this implementation plan`
- `@be-ambitious rewrite this prompt for another agent`
- `Be more ambitious about the pre-event test strategy`
